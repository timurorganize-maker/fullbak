# ЗаправкаТут ⛽

Краудсорс-сервис актуальных цен и наличия топлива на АЗС. Mobile-first PWA:
водители сами обновляют цены и наличие топлива в реальном времени. Контекст —
топливный дефицит: важно знать не только «где дешевле», но и «где вообще ЕСТЬ
топливо прямо сейчас».

> **Текущий статус — рабочий прототип** на моковых данных (18 АЗС в Казани) для
> проверки UX. Слой Supabase (схема, RLS, триггеры) готов и подключается через
> переменные окружения — см. ниже.

## Стек

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** — дизайн-система (светлая/тёмная тема, safe-area, крупная
  типографика цен)
- **MapLibre GL** + открытые тайлы CARTO/OSM (без API-ключа; готово к замене на
  Yandex Maps JS API)
- **Supabase** (Postgres + Auth + Realtime + Storage) — схема и RLS в
  `supabase/migrations`
- **PWA** — манифест, service worker, офлайн-очередь репортов

## Возможности прототипа

- 🗺️ **Карта АЗС** — полноэкранная, геолокация, маркеры по статусу наличия
  (зелёный/жёлтый/красный/серый), кластеризация.
- 📄 **Bottom sheet** с drag-жестом (как в Яндекс/Apple Maps): бренд, цены по
  видам топлива, статус, «обновлено N назад», подтверждение данных.
- ⏱️ **Индикатор свежести** — цветовые точки (зелёный <30 мин, жёлтый <3 ч,
  серый — устарело) и счётчик «N водителей обновили за последний час».
- ⚡ **Быстрый репорт** — 2 тапа + одно поле: вид топлива → наличие/цена →
  очередь. ~10 секунд.
- ➕ **Добавление новой АЗС** (с пометкой «на модерации»).
- ⭐ **Отзывы и рейтинг** — 1–5, текст, сортировка новые/полезные.
- 🛡️ **Антиспам/доверие** — trust_score, rate-limit (1 репорт на станцию / 5 мин),
  голоса «подтверждаю/не актуально».
- 🔍 **Поиск и фильтры** — по топливу, бренду, «только с наличием», сортировка.
- 👤 **Профиль** — история репортов, trust_score, уровни, бейджи.
- 📶 **Офлайн-режим** — репорт сохраняется локально и отправляется при
  восстановлении сети.

## Запуск

```bash
npm install
npm run dev
# http://localhost:3000 — откройте в мобильном вьюпорте (DevTools → iPhone)
```

Прототип работает **без бэкенда** на моковых данных. Чтобы подключить реальные
данные:

1. Создайте проект в [Supabase](https://supabase.com).
2. Примените миграции из `supabase/migrations/*.sql` (SQL Editor или Supabase CLI).
3. Скопируйте `.env.example` → `.env.local` и заполните `NEXT_PUBLIC_SUPABASE_URL`
   и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.

## Структура

```
src/
  app/                 # App Router (layout, главная страница-карта, globals.css)
  components/
    map/               # MapView (MapLibre), FilterBar
    station/           # детали станции, список, отзывы
    report/            # быстрый репорт, добавление АЗС
    profile/           # профиль, trust_score, бейджи
    ui/                # bottom sheet, кнопки, индикаторы свежести
  lib/
    domain.ts          # логика «актуальной» цены/наличия, свежесть, уровни
    store.tsx          # клиентский стор (репорты, голоса, rate-limit, офлайн)
    mock-data.ts       # 18 АЗС в Казани с историей репортов
    supabase/          # клиент (активируется через env)
supabase/migrations/   # схема БД, RLS-политики, триггеры доверия, сид
public/                # PWA-манифест, иконки, service worker
```
